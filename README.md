# Visualize Fotografia — seleção de álbuns

Página independente construída somente com HTML, CSS e JavaScript. As capas são derivadas dos seis arquivos da pasta `portfolio fotos/capas`.

## Abrir

Dê dois cliques em `index.html`. Não é necessário instalar dependências.

Para testar com um servidor local, abra um terminal nesta pasta e execute:

```sh
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Interação

- Arraste os cartões para os lados no mouse ou no toque.
- Use a roda do mouse, os botões ou as setas do teclado.
- O layout se adapta a telas de computador e celular.

## Álbum Paulo

A página `paulo/paulo.html` reúne as 20 fotografias únicas do ensaio em uma direção visual inspirada no basquete. O card Paulo da página inicial abre esse álbum, que inclui galeria responsiva e visualização ampliada com navegação por setas.

Ao abrir o álbum, uma transição imersiva amplia a capa até a nova página. A trilha incorporada do YouTube começa silenciada por exigência dos navegadores e pode ser ativada e ajustada pelo controle no canto inferior direito.
